## What Is a SOC Analyst?

A Security Operations Center (SOC) Analyst monitors security alerts, investigates suspicious activities, and helps organizations respond to potential cyber threats.

### Key Responsibilities

- Monitor security alerts and events.
- Analyse system and network logs.
- Investigate suspicious login attempts.
- Support incident response activities.
- Document security findings.
- Escalate potential threats to the relevant security team.

## Essential Skills for SOC Analyst Jobs

### 1. Networking Fundamentals

Learn IP addresses, DNS, TCP/IP, ports, and common network protocols.

### 2. Linux and Windows

Understand operating systems, system logs, file permissions, and security events.

### 3. SIEM Tools

Learn how Security Information and Event Management (SIEM) tools help collect and analyse security events. Beginners can explore Splunk and Microsoft Sentinel through official learning resources.

### 4. Log Analysis

Practise identifying unusual login attempts, suspicious activities, and unexpected system events using sample security logs.

### 5. Incident Response

Understand how security teams investigate, document, and respond to cybersecurity incidents.
